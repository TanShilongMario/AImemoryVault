# 分层、价值与时效

[详细规则](../skills/portable-memory/references/memory-format.md)与 Skill 打包在一起，安装后可独立读取。

| 层 | 默认读取 | 导出 |
| --- | --- | --- |
| Profile | 首先、简短 | 默认携带稳定且已确认的背景与偏好 |
| 长期 | 读取摘要，按相关性展开 | 默认携带持续目标和约定 |
| 近期 | 当前任务需要时，检查 review_after | 有效摘要用于交接 |
| 项目 | 按任务相关性 | 默认近期窗口内或活跃项目 |
| 有价值的对话 | 按任务需要 | 重要纠正、决策理由、结论、未解决问题 |
| 候选、原文、归档 | 核实时按需 | 不默认导出 |

近期初始窗口 30 天可调整，retain:true 与 unresolved 讨论可以越过窗口。旧的重要内容值得保留，新临时问答可以跳过。缺少元数据的历史项目由 Agent 判断并显式纳入，不以复制日期认定最近活跃。

确认状态、来源、范围和当前用户更正决定冲突判断；“更晚”不自动代表“更可信”。项目要求不升级成全局偏好，过期状态不继续当作当前进度。这些是读取与判断规则，不是模型内部数值权重。
